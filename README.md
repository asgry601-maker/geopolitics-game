# ⚔ ژئوپلیتیک: رقابت قدرت‌ها

یک بازی استراتژیک و ژئوپلیتیک متنی با **۹ قدرت واقعی جهان** (آمریکا، چین، روسیه، هند، آلمان، ژاپن، فرانسه، بریتانیا، ایران).

هر بازیکن رهبر یک کشور است و از سال ۲۰۲۵ تا ۲۰۶۵ (۴۰ نوبت سالانه) باید اقتصاد، ارتش، فناوری و دیپلماسی کشورش را مدیریت کند و در پایان ابرقدرت بی‌رقیب جهان شود.

## ✨ امکانات

- 🌍 کشورهای واقعی با آمار تقریبی مبتنی بر داده‌های ۲۰۲۴ (اقتصاد، ارتش، فناوری، ثبات، کلاهک هسته‌ای)
- 🤝 روابط اولیه واقع‌گرایانه بین همه کشورها (آمریکا–ایران −۷۵، چین–ایران +۵۰، ...)
- 🏛 **احزاب داخلی** برای همه ۹ کشور که به رخدادها واکنش نشان می‌دهند — ائتلاف حاکم ضعیف = خطر انقلاب
- 📰 **مطبوعات** با سوگیری سیاسی متفاوت: هر کشور روزنامه‌های خودش را دارد و به جنگ، ترور، تحریم و رونق تیتر می‌زند
- 🕵 جاسوسی، 💥 خرابکاری و ☠ ترور — هم برای بازیکن، هم هوش مصنوعی!
- ⚔ جنگ و الحاق کشورها، تشکیل ائتلاف، تحریم و پروژه هسته‌ای
- 🎲 رخدادهای تصادفی جهانی (بحران انرژی، همه‌گیری، خیزش مردمی، جهش فناوری)
- 💾 ذخیره‌سازی خودکار بازی در `game_state.json`

## 🚀 اجرا

فقط پایتون ۳ لازم است (بدون هیچ وابستگی اضافه):

```bash
python3 geopolitics.py init ایران    # شروع بازی با کشور دلخواه
python3 geopolitics.py status       # وضعیت جهان
python3 geopolitics.py help         # راهنمای کامل
```

## 🎮 فرمان‌ها (هر نوبت ۲ فرصت)

| فرمان | توضیح | هزینه |
|---|---|---|
| `act eco` | سرمایه‌گذاری اقتصادی | ۴۰ |
| `act mil` | تقویت ارتش | ۵۰ |
| `act tech` | پژوهش فناوری | ۳۵ |
| `act nuke` | برنامه هسته‌ای (فناوری ≥ ۷۰) | ۱۲۰ |
| `act spy <کشور>` | جاسوسی | ۱۵ |
| `act aide <کشور>` | کمک اقتصادی → بهبود روابط | ۳۰ |
| `act trade <کشور>` | قرارداد تجاری | ۲۰ |
| `act pact <کشور>` | پیمان عدم تجاوز | ۱۰ |
| `act ally <کشور>` | اتحاد نظامی | ۲۵ |
| `act sanc <کشور>` | تحریم اقتصادی | رایگان |
| `act covert <کشور>` | عملیات مخفی: بی‌ثبات‌سازی | ۵۰ |
| `act propaganda` | تبلیغات حزبی | ۲۰ |
| `act sabotage <کشور>` | خرابکاری در صنایع دفاعی | ۴۵ |
| `act kill <کشور>` | ☠ ترور رهبر دشمن | ۸۰ |
| `act war <کشور>` | اعلام جنگ ⚔ | رایگان |
| `end` | پایان نوبت (نوبت کشورهای دیگر + رخداد تصادفی) | — |

## 🏆 شرایط پیروزی

- امتیاز سلطه ≥ ۵۵ و حداقل ۱.۵ برابر رقیب دوم، **یا**
- رتبه ۱ جهان در سال ۲۰۶۵

⚠ ثبات صفر = انقلاب وGAME OVER — سلامت ائتلاف حاکم را جدی بگیر!
