# ⚔ ژئوپلیتیک: رقابت قدرت‌ها

یک بازی استراتژیک و ژئوپلیتیک متنی با **۱۷۴ کشور واقعی جهان** در **۹ منطقه** — از آمریکا و چین گرفته تا ایران، ترکیه، عربستان و قزاقستان.

هر بازیکن رهبر یک کشور است و از سال ۲۰۲۵ تا ۲۰۶۵ (۴۰ نوبت سالانه) باید اقتصاد، ارتش، فناوری و دیپلماسی کشورش را مدیریت کند و در پایان ابرقدرت بی‌رقیب جهان شود.

## ✨ امکانات

- 🌍 **۱۷۴ کشور واقعی** با آمار تقریبی مبتنی بر داده‌های ۲۰۲۴ — ۵ سطح قدرت، ۲۱ کشور ویژه با جزئیات کامل
- 🗺 ۹ منطقه (خاورمیانه، اروپا، شرق آسیا، جنوب آسیا، آمریکای شمالی، آمریکای لاتین، آفریقا، آسیای مرکزی و قفقاز، اقیانوسیه)
- 🤝 روابط اولیهٔ واقع‌گرایانه: دشمنی‌های تاریخی (روسیه–اوکراین، اسرائیل–فلسطین، کره‌شمالی–کره‌جنوبی...)، دوستی‌های استراتژیک، اعضای ناتو و متحدان آمریکا
- 🏛 **احزاب داخلی برای همهٔ ۱۷۴ کشور** که به رخدادها واکنش نشان می‌دهند — ائتلاف حاکم ضعیف = خطر انقلاب
- 📰 **مطبوعات** با سوگیری سیاسی متفاوت: هر کشور روزنامه‌های خودش را دارد و به جنگ، ترور، تحریم و رونق تیتر می‌زند
- 🗡 **نیروهای نیابتی**: شبکه‌های مخفی شبه‌نظامی در خاک کشورهای دیگر بساز، قدرتشان را تا ۵ بالا ببر — اما مواظب باش لو نروند! (کشورهای هوش مصنوعی هم شبکه‌ی نیابتی می‌سازند)
- 🕵 جاسوسی، 💥 خرابکاری و ☠ ترور — هم برای بازیکن، هم هوش مصنوعی
- ⚔ جنگ و الحاق کشورها، تشکیل ائتلاف، تحریم و پروژه هسته‌ای
- 🎲 رخدادهای تصادفی جهانی (بحران انرژی، همه‌گیری، خیزش مردمی، جهش فناوری)
- 📊 **داشبورد و منو**: وضعیت، سیاست داخلی، دیپلماسی، عملیات پنهان، نظامی و اقتصاد
- 💾 ذخیره‌سازی خودکار بازی در `game_state.json`

## 🚀 اجرا

فقط پایتون ۳ لازم است (بدون هیچ وابستگی اضافه).

### ویندوز — ساده‌ترین راه 🪟

1. اگر پایتون نداری: از [python.org/downloads](https://www.python.org/downloads/) نصب کن و حتماً تیک **Add python.exe to PATH** را بزن
2. روی فایل **`بازی.bat`** دابل‌کلیک کن — همان!
3. اولین بار: بنویس `init ایران` (یا هر کشور دیگر) و Enter بزن
4. بازی خودش ذخیره می‌شود؛ هر بار دابل‌کلیک بعدی از همان‌جا ادامه می‌دهد

### مک / لینوکس 🍎🐧

```bash
./بازی.sh
```

### بدون حالت تعاملی (فرمان‌به‌فرمان)

```bash
python3 geopolitics.py init ایران    # شروع بازی با کشور دلخواه
python3 geopolitics.py status        # وضعیت جهان
python3 geopolitics.py help          # راهنمای کامل
```

## 🎬 حالت تعاملی و منو

با اجرای `بازی.bat` وارد محیط بازی می‌شوی. در خط فرمان بازی، منوی میان‌بر نمایش داده می‌شود:

```
[1]📊 وضعیت [2]🏛 سیاست [3]🌐 دیپلماسی [4]🕵 عملیات [5]⚔ نظامی [6]💰 اقتصاد [7]✅ پایان نوبت [8]❔ راهنما [9]🌍 رتبه‌بندی
🎬 فرمان>
```

اعداد ۱ تا ۹ را بزن تا داشبورد همان بخش باز شود؛ یا فرمان‌ها را مستقیم بنویس.

## 📊 داشبورد و دیدن کشورها

| فرمان | توضیح |
|---|---|
| `dash` | نمایش همهٔ داشبوردها پشت‌سرهم |
| `dash dom` | 🏛 سیاست داخلی — حزب‌ها، ائتلاف حاکم، تیترهای مطبوعات |
| `dash dip` | 🌐 دیپلماسی — متحدان، گرم‌ترین روابط، تنش‌ها، نمای منطقه‌ای |
| `dash ops` | 🕵 عملیات پنهان — شبکه‌های نیابتی تو و بیگانه در خاکت |
| `dash mil` | ⚔ قدرت نظامی تو در برابر قوی‌ترین‌های جهان |
| `dash eco` | 💰 خزانه، درآمد سالانه، بزرگ‌ترین اقتصادها |
| `status ترکیه` | 📊 پروندهٔ کامل یک کشور (آمار، رتبه، رابطه، حزب‌ها، شبکهٔ نیابتی) |
| `rank` | 🌍 رتبه‌بندی کامل همهٔ ۱۷۴ کشور |
| `list` | فهرست کشورها به تفکیک منطقه (مثال: `list خاورمیانه`) |

## 🎮 فرمان‌ها (هر نوبت ۲ فرصت)

| فرمان | توضیح | هزینه |
|---|---|---|
| `act eco` | سرمایه‌گذاری اقتصادی | ۴۰ |
| `act mil` | تقویت ارتش | ۵۰ |
| `act tech` | پژوهش فناوری | ۳۵ |
| `act nuke` | برنامه هسته‌ای (فناوری ≥ ۷۰) | ۱۲۰ |
| `act spy <کشور>` | جاسوسی | ۱۵ |
| `act aide <کشور>` | کمک اقتصادی → بهبود روابط | ۳۰ |
| `act trade <کشور>` | قرارداد تجاری | ۲۰ |
| `act pact <کشور>` | پیمان عدم تجاوز | ۱۰ |
| `act ally <کشور>` | اتحاد نظامی | ۲۵ |
| `act sanc <کشور>` | تحریم اقتصادی | رایگان |
| `act covert <کشور>` | عملیات مخفی: بی‌ثبات‌سازی | ۵۰ |
| `act propaganda` | تبلیغات حزبی | ۲۰ |
| `act sabotage <کشور>` | خرابکاری در صنایع دفاعی | ۴۵ |
| `act kill <کشور>` | ☠ ترور رهبر دشمن | ۸۰ |
| `act proxy <کشور>` | 🗡 شبکهٔ نیابتی مخفی (تکرار برای تقویت) | ۶۰ / ۴۰ |
| `act war <کشور>` | اعلام جنگ ⚔ | رایگان |
| `end` | پایان نوبت (نوبت کشورهای دیگر + رخداد تصادفی) | — |

### 💡 نکتهٔ نیروهای نیابتی

- `act proxy عراق` شبکه‌ای مخفی در عراق می‌سازد (ثبات عراق می‌افتد)
- تکرار همان فرمان قدرت شبکه را تا **۵/۵** زیاد می‌کند (قوی‌تر = عملیات پرتعدادتر)
- هر سال هم سود دارد (نفوذ برای تو) و هم خطر: ممکن است شبکه در عملیات گسترده یا کشف، افشا شود
- کشورهای هوش مصنوعیِ پرخاشگر هم به خاک تو شبکه می‌ریزند — از `dash ops` پیگیری کن
