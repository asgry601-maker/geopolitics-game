# تصاویر رهبران کشورها

این پوشه برای تصاویر پرتره رهبران در داشبورد کشورهاست.

## نام‌گذاری
برای هر کشور یک تصویر با کد ISO3 قرار بده؛ نمونه:
- `IRN.jpg`
- `USA.jpg`
- `DEU.jpg`

فرمت‌های پشتیبانی‌شده: JPG، JPEG، PNG و WebP. مسیر فایل‌ها در بازی به شکل `assets/leaders/ISO3.jpg` است.

## وضعیت بسته
در حال حاضر مسیر و نمایش تصویر در رابط کاربری آماده شده، اما مجموعه تصاویر واقعی هنوز گردآوری و به بسته اضافه نشده است. تا زمان اضافه‌شدن هر تصویر، داشبورد جای‌نگهدار «تصویر ثبت نشده» را نشان می‌دهد.

تصاویر بعدی باید با هویت درست رهبر و تاریخ سناریو تطبیق داده شوند و منبع و مجوز استفاده آن‌ها ثبت شود. از تصویر حدسی یا بدون منبع استفاده نشود.
