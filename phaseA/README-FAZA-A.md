# 🌍 فاز A — کره سه‌بعدی ژئوپولیتیک (نسخه آزمایشی مستقل)

این پوشه یک **افزونه مستقل** است: هیچ فایلی از بازی اصلی حذف یا تغییر نکرده و موتور
`geopolitics.py` دست‌نخورده باقی مانده. بازی گرافیکی فقط از طریق یک لایه پل JSON
(`geopolitics_api.py`) با موتور صحبت می‌کند.

## تركیب فایل‌ها

| مسیر | نقش |
|---|---|
| `START-WORLD.bat` | لانچر دابل‌کلیک (Python را می‌یابد، موتور را معرفی می‌کند و سرور را بالا می‌آورد) |
| `geopolitics_api.py` | پل JSON بین موتور متن و بازی گرافیکی — فقط loopback (127.0.0.1) |
| `world/world.html` + `world/world.js` | صفحه بازی گرافیکی (RTL، Tahoma، بدون نیاز به اینترنت) |
| `lib/three.min.js` + `lib/globe.gl.min.js` | موتور گرافیکی — three.js r126 + globe.gl 2.21.0 (سازگار WebGL 1) |
| `data/countries.geojson` | مرز ۱۷۷ سرزمین Natural Earth 110m |
| `data/country_map.json` | ترجمه نام فارسی ↔ انگلیسی/ISO + مرکز جغرافیایی (تولیدشده با `tools/build_country_map.py`) |
| `img/earth-dark.jpg`، `img/earth-blue-marble.jpg` | دو بافت کره (تیره سبک / واقعی) |
| `api_key.local` (اختیاری، خودت بساز) | کلید هوش مصنوعی آنلاین — **فقط سمت سرور**، هرگز به مرورگر نمی‌رود |
| `engine/` | **کپی کامل** موتور متن بازی (geopolitics.py، نسخه وب متن و لانچرها) — نسخه اصلی دست‌نخورده می‌ماند |

## استخراج ZIP و اجرا

ZIP را در هر جایی می‌توانی استخراج کنی؛ دو حالت پشتیبانی می‌شود:

**حالت ۱ — مستقل (پیشنهادی):**
ZIP را در یک پوشه جدید استخراج کن (مثلاً `D:\Games\geopolitics-faza-A\`).
پوشه `engine` داخل ZIP موجود است و بازی بدون هیچ چیز دیگری کار می‌کند.
دستور اجرا: `START-WORLD.bat`
دستور اجرا نسخه متنی قدیمی داخل همین بسته: `engine\play.bat` یا `engine\web.bat`

**حالت ۲ — در کنار یا داخل پوشه بازی فعلی:**
اگر پوشه استخراج‌شده را داخل پوشه بازی اصلی بگذاری هم کار می‌کند؛
تشخیص خودکار موتور به این ترتیب است:
`GEO_ENGINE_DIR` (محیط) ← `engine/` کنار API ← همان پوشه ← `github__asgry601-maker__geopolitics-game` ← پوشه والد ← پوشه home.

نکات مهم:
- فایل وضعیت بازی (`game_state.json`) موتور در پوشه موتورِ انتخاب‌شده ساخته می‌شود؛
  نسخه گرافیکی و نسخه متنی اگر موتور جدا داشته باشند **وضعیت جدا** دارند (برای آزمایش موازی خوب است).
- پورت پیش‌فرض 8731 است؛ اگر اشغال بود خودکار پورت آزاد انتخاب می‌شود (پیام کنسول).
- اگر استخراج کردی و موتور پیدا نشد، کنسول پیام «پوشه بازی پیدا نشد» می‌دهد؛
  مسیر را در متغیر `GEO_ENGINE_DIR` ست کن یا پوشه `engine` را بازیابی کن.
- نسخه گرافیکی نیازی به اینترنت ندارد (کتابخانه‌ها آفلاین داخل بسته‌اند)؛
  فقط هوش مصنوعی آنلاین فاز F بعداً اینترنت می‌خواهد.
- برای توقف سرور: پنجره bat را ببند یا Ctrl+C.

## اجرا

```text
START-WORLD.bat   →  مرورگر خودکار روی http://127.0.0.1:8731/ باز می‌شود
```

اگر پورت 8731 اشغال بود، سرور خودش یک پورت آزاد انتخاب می‌کند (پیام کنسول را ببین).

## چیزهای فاز A

1. کره زمین سه‌بعدی واقعی (چرخش با کشیدن ماوس، بزرگ‌نمایی با چرخ ماوس یا 🔍+/−).
2. مرز کشورها + نام فارسی همه ۱۷۴ کشور (۹ میکروکشور فاقد مرز در داده، به‌صورت نقطه‌نشانه).
3. انتخاب کشور با کلیک روی خشکی **یا** کلیک روی نام — پنل اطلاعات در همان صفحه باز می‌شود
   (بدون خروج از صفحه): رهبر واقعی، آمار ملی با نوار شدت، رابطه با شما، جنگ‌ها، تجهیزات،
   احزاب، دوستان/دشمنان، نیابتی‌ها و آخرین اخبار داخلی.
4. رنگ‌بندی دوحالته با دکمه 🎨:
   - **جغرافیایی**: ۹ منطقه با ۹ رنگ ثابت.
   - **سیاسی**: بر اساس رابطه با کشور بازیکن (سبز تیره ≥40، روشن ≥10، خاکستری ±۱۰،
     نارنجی ≤ −10، قرمز ≤ −40، تیره‌ترین = جنگ).
5. اتصال زنده به داده Python: پایان روز ☀️ از طریق موتور واقعی انجام و نتیجه نشان داده می‌شود.
6. شروع بازی از خود صفحه گرافیکی (اگر `game_state.json` موجود نباشد).
7. بهینه‌سازی سخت‌افزار ضعیف: بدون antialias، pixelRatio ≤ 1.5، بافت تیره پیش‌فرض،
   شمارنده FPS گوشه پایین.

## چیزهایی که در فازهای بعدی می‌آید

- **B**: داشبورد ۱۲بخشی کامل کشوری در همان پنل.
- **C**: ۸ نوع زیرساخت انتزاعی روی نقشه.
- **D**: افکت‌های نظامی نمادین (قوس پرتاب/انفجار انتزاعی — بدون جزئیات عملیاتی).
- **E**: اخبار پویا از رسانه‌های داخل بازی.
- **F**: هوش مصنوعی مکالمه‌ای آنلاین — معماری endpoint از همین فاز در
  `geopolitics_api.py > api_chat` پیش‌بینی شده است.
  کلید API را در فایل `api_key.local` (کنار `geopolitics_api.py`) با این ساختار بگذار:

```json
{"provider": "openai", "key": "sk-...", "model": "gpt-4o-mini"}
```

این فایل هیچ‌وقت سرو نمی‌شود و در گیت هم قرار نمی‌گیرد؛ فقط سرور آن را می‌خواند.
