# Third-party data and flag notices

This game bundles locally stored country reference data and SVG flag artwork.

## Sources

- Country capital, language, currency and ISO reference: [annexare/Countries](https://github.com/annexare/Countries), MIT License.
- Population: World Bank indicator SP.POP.TOTL (2024), distributed through [iliyaj/country-data](https://github.com/iliyaj/country-data), MIT License.
- GDP: World Bank indicator NY.GDP.MKTP.CD (2024), distributed through [iliyaj/country-data](https://github.com/iliyaj/country-data), MIT License.
- Land and water area: World Bank data distributed through [iliyaj/country-data](https://github.com/iliyaj/country-data), MIT License.
- SVG flag artwork: [lipis/flag-icons](https://github.com/lipis/flag-icons), MIT License.

## Data interpretation

- Population density is calculated as population divided by land area.
- Total area is land plus water area when both are available.
- GDP per capita is nominal GDP divided by population; it is not purchasing-power parity.
- Language lists are reference data and are not guaranteed to be an exhaustive legal list of constitutionally official languages for every country.
- A null value means the source did not provide a value; the game does not invent replacements.
- These are historical reference values, not live values and not the simulation's treasury or daily income.
